Vault Robbers — Reveal Service

Progressive, provably-fair reveal for the 1,000 Vault Robbers on Robinhood Chain.

A token's art and metadata unseal only once its tokenId is minted. Unminted tokens return a sealed placeholder, so no one can preview upcoming mints.

  • /status — live revealed / startingIndex / totalMinted
  • /provenance.json — SHA-256 provenance of the final art order
  • /meta/<art>.json — token metadata (gated)
  • /img/<art>.png — token image (gated)
