# Vault Robbers, art request

Thanks for the first 30 traits. Here is everything we need to take this to a full 1,000-piece set. Priority order top to bottom.

## 1. High-quality SVGs of every trait (already discussed)
The PNGs look blurry at size. Please send vector SVG of each existing trait.

## 2. Bodies, 5 to 7 new ones (highest priority)
We only have one real body right now (the sage puffer), so every character currently wears the same thing. Please draw a spread, for example: hoodie, denim jacket, leather jacket, prison stripes, trench coat, tactical vest, ragged shirt.

## 3. Consistent registration (important for mix and match)
- Every BODY drawn to the same neck and shoulder position.
- Every HEAD drawn to the same anchor point.
- So any head sits correctly on any body. This is what keeps the generator from misaligning.

## 4. A few more heads, 3 to 4
Heads carry the personality, more variety here pays off. Same style as the current skulls and faces.

## 5. A few more eyewear and headwear
Eyewear: eye patch, monocle, sunglasses. Headwear: bandana, hood, top hat.

## 6. File specs (please follow for all of the above)
- 2048 x 2048 square artboard, subject centered.
- Transparent background (the background is its own separate layer).
- One trait per file, named by the trait (for example `body_denim-jacket.svg`).
- Each optional layer should look finished when worn alone (a head with no hat, a body with no accessory).

## 7. Layer intent
A one-line note on which pieces sit over which (glasses on the face, hat over the head, etc.) so our stacking order matches your intent.

## 8. The 10 one-of-ones (can be fully off-style)
Ten bespoke "famous robber" characters, each unique, do not need to match the base style. Concepts to follow in a separate brief.
